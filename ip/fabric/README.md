# FABulous Fabric

This repository hosts the fabric configuration for the [FABulous](https://github.com/FPGA-Research/FABulous) framework.

In order to implement the fabric, please use version 1.2.0 of [librelane_plugin_fabulous](https://github.com/mole99/librelane_plugin_fabulous/releases/tag/1.2.0).

Enable the Nix shell of the plugin and implement using `make fabric`.

To view the layout of the fabric, run `make fabric-openroad` or `make fabric-klayout`.
